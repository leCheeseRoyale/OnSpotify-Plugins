# OnSpotify-Plugins

Plugin marketplace for Claude Code by Showerhead.

## Available Plugins

### [trading-experiment](https://github.com/leCheeseRoyale/trading-experiment)

Autonomous crypto strategy researcher. Describe a trading idea in plain English and Claude will design experiments, write strategy code, run backtests with out-of-sample validation, and iterate until it finds something that works.

**Features:** 11 MCP tools, automatic overfitting detection, helper library that grows across experiments, support for any ccxt exchange.

## Installation

Add this marketplace to Claude Code:

```
/plugin marketplace add leCheeseRoyale/OnSpotify-Plugins
```

Then install any plugin:

```
/plugin install trading-experiment@OnSpotify-Plugins
```
