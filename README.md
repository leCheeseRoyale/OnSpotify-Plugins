# OnSpotify-Plugins

Plugin marketplace for Claude Code by Showerhead.

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [trading-experiment](https://github.com/leCheeseRoyale/trading-experiment) | Autonomous crypto strategy research via backtesting |

## Installation

```bash
/plugin marketplace add leCheeseRoyale/OnSpotify-Plugins
/plugin install trading-experiment@OnSpotify-Plugins
```
